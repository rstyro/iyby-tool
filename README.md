# 🎉 JoyTool | 实用有趣工坊 🛠️
> 一款「好用又好玩」的跨端小程序，专治无聊 + 解决刚需！

## 🌟 为什么选择 joy-tool？
- **告别臃肿**：没有花里胡哨的功能，只留「实用+有趣」双核心
- **跨端自由**：手机浏览器能打开，微信小程序也能玩，无缝切换
- **开发友好**：uni-app + Vue2 开发，小白也能轻松二次开发
- **完全免费**：无广告、无付费，放心使用

## 🚀 功能速览
| 分类     | 功能清单                             |
|----------|----------------------------------|
| 实用工具 | 手持弹幕 / 二维码生成 / 生肖吉凶分析 / 2FA身份验证器 |
| 趣味玩法 | 幸运大抽奖 / 酒桌猜骰子/ 情侣飞行棋 /翻牌子        |
| 彩蛋功能 | 隐藏小互动（等你发现哦😜）                   |

## 💻 技术小栈
- 驱动引擎：uni-app + Vue2
- 运行平台：H5 / 微信小程序
- 开发工具：HBuilderX（谁用谁知道！）

## 🎈 快速玩起来
```bash
# 拉取项目到本地
git clone https://github.com/rstyro/joy-tool.git

# 进入快乐星球
cd joy-tool

# 安装依赖
npm install

# 启动 H5 版（浏览器直接玩）
npm run dev:h5

# 启动小程序版（微信开发者工具导入）
npm run dev:mp-weixin
